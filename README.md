# LaunchKit — Marketing MVP Experiment Toolkit

یک ابزار کوچک و متن‌باز برای تبدیل ایده بازاریابی به آزمایش قابل‌اندازه‌گیری. این نسخه MVP کاملاً سمت مرورگر اجرا می‌شود و به سرور، حساب کاربری یا کلید API نیاز ندارد.

## قابلیت‌ها

- تعریف پروژه، مخاطب، مسئله و فرضیه آزمایش
- ساخت پیش‌نویس پیشنهاد ارزش و CTA
- محاسبه نرخ تبدیل بازدیدکننده به لید، هزینه هر لید و نرخ تبدیل لید به مشتری
- دریافت خروجی JSON از آزمایش
- رابط فارسی و واکنش‌گرا
- بدون ارسال اطلاعات به سرور

## اجرای محلی

۱. فایل‌ها را دانلود یا مخزن را clone کنید.
۲. `index.html` را در مرورگر باز کنید.

برای توسعه محلی می‌توانید از افزونه Live Server در VS Code استفاده کنید. هیچ مرحله build لازم نیست.

## نقشه راه

- [ ] ذخیره و بارگذاری چند آزمایش در مرورگر
- [ ] الگوهای آماده برای SaaS، خدمات و فروشگاه اینترنتی
- [ ] معیارهای CAC، درآمد و ROAS
- [ ] نسخه انگلیسی
- [ ] تست‌های خودکار برای محاسبات
- [ ] راهنمای آزمایش A/B

## محدودیت‌های نسخه فعلی

- اعداد نمونه صرفاً نمایشی‌اند؛ پیش از تصمیم‌گیری، با داده واقعی جایگزینشان کنید.
- این ابزار جایگزین تحلیل آماری، تحقیقات مشتری یا مشاوره تخصصی نیست.
- داده‌ها بین دستگاه‌ها همگام‌سازی نمی‌شوند.

## مشارکت

۱. یک Issue با شرح مشکل یا پیشنهاد بسازید.
۲. برای تغییرات کوچک یک شاخه جداگانه ایجاد کنید.
۳. تغییر را همراه با توضیح و در صورت امکان تصویر ارسال کنید.
۴. برای تغییرات محاسباتی، تست یا مثال عددی اضافه کنید.

## انتشار روی GitHub

۱. در GitHub یک مخزن **Public** با نام `launchkit-marketing-mvp` بسازید.
۲. فایل‌های این پوشه را در مخزن بارگذاری کنید.
۳. در بخش About توضیح زیر را بنویسید:

> A lightweight, open-source marketing experiment toolkit to define hypotheses, craft value propositions, and measure early funnel metrics.

۴. موضوع‌های پیشنهادی: `marketing`, `mvp`, `growth`, `conversion-rate-optimization`, `persian`, `open-source`.
۵. اگر قصد دارید پروژه را برای برنامه‌ای مثل Claude for Open Source معرفی کنید، فقط وقتی ادعا کنید که پروژه عمومی و قابل‌مشاهده است که واقعاً منتشر شده باشد؛ شرایط رسمی برنامه را هم جداگانه بررسی کنید.
